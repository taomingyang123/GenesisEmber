# 创世余烬 · 微信小游戏

根据 `evolve_web/rna.html` 迁移的纯 JavaScript / Canvas 2D 微信小游戏。原始及增强网页 H5 版统一存放在 `evolve_web/` 目录中。小游戏入口和微信项目配置位于项目根目录，不需要 npm 安装、构建、游戏引擎、服务器或外部素材。

## 在微信开发者工具中运行

1. 打开微信开发者工具，选择导入项目，目录选**GenesisEmber 根目录**。
2. 项目使用根目录配置中已有的小游戏 AppID。
3. 确认项目类型为**小游戏**（配置项 `compileType: "game"`），基础库使用当前稳定版本，点击编译。
4. 使用工具的「预览」在微信中测试。上传和提交审核需使用已开通小游戏的账号。

当前开发环境已安装微信开发者工具，但其命令行服务端口关闭，所以本次没有完成开发者工具编译或手机实机验证。可以直接通过工具界面导入；如需 CLI 调试，在工具「设置 → 安全设置」中开启服务端口。

## 本地快速预览

需要 Node.js 18 或以上，无需安装依赖：

```sh
npm run preview
```

打开终端显示的本机预览地址（默认 `http://127.0.0.1:4173`）。手机模式下点击舞台采集、拖动功能页列表；桌面可用滚轮滚动，空格采集。预览使用独立浏览器存档，不会自动读写微信中的数据。`PORT=4174 npm run preview` 可更换端口。

浏览器预览是开发辅助入口。项目配置会从微信包中排除开发工具、测试、说明、截图和原版 HTML。

## 保留的玩法

- 7 个时代：生命起源、农业、城市、工业、原子、信息、太空。
- 26 种资源、8 个生命进化节点、12 种职业、35 种建筑、44 项科技（包含 8 个进化节点）。
- 51 个顺序任务、7 类各 5 级的永久天赋、方舟跃迁与余烬加成。
- 人口、幸福度、仓储、批量建造、电力与工业配方。
- 原版 64×64 时代动画，15 FPS 绘制、250ms 模拟周期。
- 音效、扫描线开关、30 秒自动保存、存档导入导出。

界面沿用原版 HTML 的 768px 布局断点。手机上下排列，桌面使用 390px 左栏和独立右侧页签。点资源条可定位到库存列表，点顶部任务可定位到当前任务；功能列表滑动时不会触发购买。

## 存档迁移

1. 在 H5 版 `evolve_web/rna.html` 的「资源/设置」中导出并复制存档码。
2. 在小游戏中打开「资源/设置」，点击「导入存档码」。
3. 确认替换当前进度。导入前可先用「导出存档码 → 复制存档码」备份当前游戏。

格式与原版 v3 的 UTF-8 JSON / Base64 存档兼容。浏览器与微信的本地存储相互隔离，因此通过存档码迁移。小游戏只会在玩家主动点击导入时读取剪贴板。

微信使用 `wx.getStorageSync/setStorageSync`，键名为 `pixel_human_era_save_v3`。存档损坏时尝试备份到同名加 `_unreadable` 的键。存储写入失败时会提示玩家。

切后台立即保存并暂停模拟，回前台结算离线收益；冷启动结算后立即保存，避免重复结算。同原版，基础离线上限 8 小时，休眠天赋逐级提升到 48 小时。离线采用最长 5 秒一步的近似模拟，复杂缺料生产链与在线 250ms 模拟可能有小幅差异。

## 目录

```text
GenesisEmber/
  game.js                 微信入口
  game.json               竖屏配置
  project.config.json     开发者工具项目配置
  js/
    app.js                生命周期、触摸、存档与主循环
    data.js               原版完整数值和任务定义
    engine.js             独立游戏逻辑与存档校验
    ui.js                 Canvas 界面、布局与滚动命中
    scene.js              七时代像素舞台
    platform.js           微信屏幕信息与音效
    save-code.js          兼容原版的存档码编解码
  assets/audio/           本地生成的四种 8-bit WAV 音效
evolve_web/               独立自包含 H5 网页版（含 rna.html、data/、js/）
tools/                    开发构建与本地微信预览脚本
tests/                    游戏逻辑、H5 模块与微信生命周期检查
artifacts/                本次预览截图
```

## 验证

```sh
npm test
```

测试包括原版数值配置对照、新玩家进化链、七时代晋升、职业分配、批量建造、电力生产、任务不重复发奖、跃迁、损坏存档处理、旧版存档码兼容、离线结算与上限、前后台切换，以及七时代五页签在 320px 小屏、刘海屏和平板尺寸下的绘制与触摸。

浏览器截图与操作检查不能替代微信实际运行。在开发者工具导入根目录后，还需在开发者工具和 iOS / Android 微信中确认音效播放、胶囊与安全区、剪贴板权限、前后台存档和长时离线结算。
